# Static Example Outputs

These files are representative examples prepared for GitHub presentation. They are intentionally static snapshots so the repository still tells a clear story even when a reviewer cannot run every tool locally.

- `sample-local-run.md`: representative output from the quick local demo
- `sample-policy-matrix.md`: visual summary of the severity and gate policy
- `sample-ci-summary.md`: representative GitHub Actions job summary
- `sample-container-scan-summary.md`: representative Trivy result and gate interpretation

Treat these files as presentation artifacts, not as authoritative runtime evidence. The executable source of truth remains the workflow, scripts, and policy documentation in the repository.
